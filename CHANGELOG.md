## [v0.3]
**29.12.25**

> Added csx - CoreScript Extension Manager
> - Accessable with the following command:

> ```bash
> CoreScript csx install <username>/<repo>/<path> -p <provider>
> ```

> Providers accepted:
> - GitHub (std.)
> - GitLab

> Local install:
> ```bash
> CoreScript csx install <path/to/extension> -p local
> ```
